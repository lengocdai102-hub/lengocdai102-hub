## 📊 做过的方向验证

**美国区 App Store 副业调研** — 用 Scrapling + 多 bot 并行采集，构建可追溯的数据管线：

| 指标 | 数值 |
|---|---|
| 竞品池 | 11,841 个 App |
| 独立开发者 App | 916 个（7.7%），仅占全池评分量 0.16–0.2% |
| TOP15 头部 | **零**独立开发者 |
| 公司主体 App | 6,729 个，占 97.84% 评分量 |
| 交叉核验 | 9/9 项独立重算通过 |

结论：**独立开发者在 App Store 拿不到规模流量**，但存在「高价值僵尸位」——43 个停更超一年、仍有 ≥500 评分的品类位置。

方法论要点：Apple 不公开下载量，用评分量 / 评论数 / 榜单排名 / 排名变化做代理指标；RSS 评论样本偏负向（写入率中位 ~4.5%），已做校准。
